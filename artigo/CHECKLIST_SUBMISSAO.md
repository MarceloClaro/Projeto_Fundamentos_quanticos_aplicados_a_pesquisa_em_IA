# Checklist de submissão científica

## A. Conteúdo científico

- [x] Pergunta de pesquisa explícita
- [x] Objetivos e hipóteses separados
- [x] Desfecho primário definido
- [x] Baseline principal pré-especificado
- [x] Resultados negativos preservados
- [x] Custos quânticos relatados
- [x] Limitações e validade externa discutidas
- [x] Piloto, diagnóstico e confirmação separados
- [ ] Execução confirmatória após aprovação OSF
- [ ] Replicação independente
- [ ] Validação externa confirmatória
- [ ] Pares-âncora QPU, somente se os portões permitirem

## B. Estatística

- [x] Comparação pareada no diagnóstico
- [x] IC95% e 5.000 reamostragens
- [x] Tamanho do teste informado
- [x] Ausência de superioridade declarada
- [ ] CV externa 4 folds × 3 repetições
- [ ] Seleção interna em 3 folds
- [ ] Correção Nadeau–Bengio
- [ ] Permutação de sinais
- [ ] TOST e tamanho de efeito
- [ ] Ajuste de Holm para desfechos secundários

## C. Reprodutibilidade

- [x] Código público
- [x] Notebook e gerador versionados
- [x] Seed e shots congelados
- [x] Versões do ambiente registradas
- [x] JSON estrito do diagnóstico
- [x] 36 testes de integração aprovados
- [x] Projeto e registro OSF vinculados
- [ ] DOI da versão de software
- [ ] Arquivo de dependências com hashes
- [ ] Execução independente em sessão limpa por segundo pesquisador

## D. Integridade editorial

- [ ] Aprovação do título pelo autor
- [ ] Aprovação do resumo pelo autor
- [ ] Aprovação das cinco palavras-chave
- [ ] Afiliação institucional confirmada
- [ ] ORCID informado
- [ ] Financiamento confirmado
- [ ] Conflitos de interesse confirmados
- [ ] Política de IA do periódico atendida
- [ ] Licença MIT/Apache harmonizada
- [ ] Periódico-alvo escolhido
- [ ] Formatação adaptada às instruções do periódico
- [ ] Figuras exportadas em resolução editorial

## E. Recomendação editorial

A versão atual é adequada como **preprint metodológico com resultados exploratórios negativos**. Para apresentação como estudo confirmatório de desempenho, os itens pendentes das seções A e B são obrigatórios.
